
# 🗂️ Kanban Board Application

A simple and intuitive **Kanban Board web application** built using **React.js** that helps users organize and manage tasks across different workflow stages.

🔗 **Live Demo:** [https://kandregulasurya.github.io/kanban-board/](https://kandregulasurya.github.io/kanban-board/)
📂 **Source Code:** [https://github.com/kandregulasurya/kanban-board](https://github.com/kandregulasurya/kanban-board)

---

## 📌 Features

* Create and manage tasks efficiently
* Organize tasks across multiple workflow stages (e.g., To Do, In Progress, Done)
* Update task status dynamically using React state management
* Clean, minimal, and user-friendly interface
* Fully responsive design for desktop and mobile devices

## 🚀 Getting Started (Local Setup)

1. Clone the repository:

   ```bash
   git clone https://github.com/kandregulasurya/kanban-board.git
   ```

2. Navigate to the project directory:

   ```bash
   cd kanban-board
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm start
   ```

5. Open your browser and visit:

   ```
   http://localhost:3000
   ```
